# Features Overview

Explore the powerful features of Meshtastic Node Mapper through visual examples.

## Interactive Map View

The heart of the application - visualize your entire mesh network on an interactive map with real-time updates.

![Map with Nodes and Search](images/map%20nodes%20search.png)

**Key Features:**
- Real-time node positioning
- Color-coded status indicators (online/offline)
- Search and filter nodes
- Zoom and pan controls
- Multiple map layer options

### Map Options

Customize your map view with various display options:

![Map Options](images/map%20options.png)

**Available Options:**
- Toggle node clusters
- Show/hide neighbor connections
- Display coverage areas
- Enable routing path visualization
- Adjust marker styles and sizes

## Node Management

### Nodes List View

Browse all nodes in your network with detailed information at a glance:

![Nodes List](images/nodes%20list.png)

**Features:**
- Sortable columns
- Quick status overview
- Hardware model identification
- Battery and signal strength indicators
- Last seen timestamps

### Node Actions

Perform actions on individual or multiple nodes:

![Actions on Nodes List](images/actions%20on%20the%20nodes%20list.png)

**Available Actions:**
- View detailed information
- Export node data
- Filter by status or hardware
- Bulk operations
- Quick navigation to map location

## Detailed Node Information

### Basic Node Info

Get comprehensive details about any node in your network:

![Node Basic Info](images/node%20basic%20info.png)

**Information Displayed:**
- Node identification (ID, hex ID, names)
- Hardware model and firmware version
- Current status and connection info
- GPS coordinates and altitude
- Battery level and voltage
- Signal strength (RSSI/SNR)

### Advanced Node Details

Dive deeper into node metrics and telemetry:

![Node Details](images/node%20details%201.png)

**Detailed Metrics:**
- Device telemetry (battery, voltage, temperature)
- Environmental sensors (humidity, pressure)
- Position history with timeline
- Message history
- Neighbor connections

### LoRa Configuration

View LoRa-specific settings and performance metrics:

![Node Details LoRa](images/node%20details%20lora.png)

**LoRa Information:**
- Channel configuration
- Spreading factor and bandwidth
- Coding rate
- Frequency settings
- Air time utilization
- Channel utilization percentage

## Additional Features

### Multi-Network Support
- Manage multiple mesh networks from one interface
- Switch between networks seamlessly
- Compare network performance
- Cross-network analytics

### Coverage Analysis
- Visualize signal coverage areas
- Identify coverage gaps
- Plan optimal node placement
- Terrain-aware analysis

### Data Export
- Export in multiple formats (CSV, JSON, KML, GeoJSON)
- Scheduled automated exports
- Backup and restore functionality
- Custom field selection

### Mobile Optimization
- Responsive design for phones and tablets
- Touch-optimized controls
- Offline mode for field use
- GPS integration
- Reduced data usage

### Security Features
- User authentication and authorization
- Role-based access control
- API key management
- Secure session handling
- Rate limiting

### Real-Time Updates
- WebSocket-based live updates
- Instant node status changes
- Real-time message notifications
- Live telemetry streaming
- Connection status monitoring
